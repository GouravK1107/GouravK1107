## About Me

I'm a backend developer focused on building **scalable systems** and **practical AI solutions** for real-world problems.

- I use AI to accelerate development, **not to replace engineering**. The architecture, logic, workflow and technical decisions behind every project are mine.
- I enjoy building products that solve real problems, not just applications with features.
- Primary focus: **Backend Development** with Python, Django, Flask, REST APIs and SQL, with an emphasis on clean architecture and scalable APIs.
- Alongside backend work, I build **AI-powered solutions** that improve workflows and automate repetitive tasks. AI creates value when it's used with purpose, not because it's trending.
- I like understanding users before writing code. Features aren't just components, they're user interaction points.
- Currently sharpening: **Backend Engineering, Applied AI, System Design** and problem-solving, one project at a time.
- Education: BCA (Bachelor of Computer Applications), CGPA **9.28 / 10**.
- Genuinely interested in **AI & Machine Learning**, actively exploring the space and working to add it to my professional skill set.
